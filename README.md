**Skyline** is a small pure-Canvas-2D flight game: a chase-camera aircraft banks and pitches over a gridded landscape of hills and clouds, with airspeed, altitude, heading and vertical-speed instruments, a runway on final approach, and a landing-or-crash ending. It runs offline from static ES modules with no network calls and no libraries.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Play with **W/S** or **↑/↓** to pitch, **A/D** or **←/→** to roll, and hold **Space** for throttle (release to ease off). Line up with the runway and touch down gently.

Screenshot scenes are available at `?shot=start`, `?shot=play` and `?shot=end` (optionally with `&seed=N`).
